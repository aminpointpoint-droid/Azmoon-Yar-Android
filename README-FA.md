# آزمون‌یار اندروید — پروژه ساخت APK

این مخزن، نسخه وب آفلاین آزمون‌یار را داخل یک پوسته Android WebView قرار می‌دهد. فایل‌های وب داخل APK بسته‌بندی می‌شوند؛ بنابراین برای اجرای برنامه به هاست یا اینترنت نیاز نیست.

## قابلیت انتخاب پوشه در بوک‌یار

در بخش تنظیمات کتاب، دکمه اتصال پوشه در APK از انتخاب‌گر بومی اندروید (`ACTION_OPEN_DOCUMENT_TREE`) استفاده می‌کند. دسترسی خواندن پوشه با مجوز پایدار سیستم‌عامل ذخیره می‌شود. فایل‌های تصویری به‌صورت تنبل و جداگانه از پوشه خوانده می‌شوند و به شکل Base64 یا کپی کامل در حافظه جاوااسکریپت قرار نمی‌گیرند. PDFهای منبع با PDFخوان نصب‌شده روی دستگاه باز می‌شوند.

این قابلیت برای پوشه‌های معمولی حافظه دستگاه و کارت حافظه طراحی شده است. اندروید برای برخی مسیرهای سیستمی، از جمله `Android/data`، محدودیت دارد. در صورت جابه‌جایی یا حذف پوشه، ممکن است لازم باشد دوباره آن را انتخاب کنید.

## ساخت APK با GitHub Actions

۱. این پوشه را از حالت ZIP خارج کنید.
۲. در GitHub یک مخزن **Private** و خالی بسازید؛ هنگام ساخت مخزن README، License و .gitignore را خودکار اضافه نکنید.
۳. در ترمینال Git Bash وارد پوشه پروژه شوید و دستورها را اجرا کنید:

```bash
git init
git add .
git commit -m "Initial Android APK project"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

`USERNAME` و `REPOSITORY` را با نام حساب و مخزن خودتان جایگزین کنید.

۴. در صفحه مخزن GitHub به زبانه **Actions** بروید. گردش‌کار **Build Android APK** را باز کنید و در صورت نیاز روی **Run workflow** بزنید. با هر push به شاخه `main` نیز ساخت به‌صورت خودکار اجرا می‌شود.
۵. پس از پایان موفق، وارد اجرای همان Workflow شوید و از بخش **Artifacts** فایل `Azmoon-Yar-Android-debug-APK` را دانلود کنید. داخل ZIP خروجی، فایل `app-debug.apk` قرار دارد.
۶. APK را به تبلت منتقل و نصب کنید. برای نصب خارج از فروشگاه، ممکن است اندروید اجازه نصب از منبعی را که فایل را از آن باز می‌کنید بخواهد.

## نکات مهم نسخه اول

- این خروجی، APK آزمایشی Debug است و برای نصب و تست مستقیم مناسب است؛ هنوز نسخه Release امضاشده با کلید اختصاصی انتشار نیست.
- حداقل نسخه Android در تنظیمات پروژه API 21 (Android 5.0) است. عملکرد واقعی به نسخه Android System WebView دستگاه هم وابسته است.
- ابتدا اتصال پوشه در بوک‌یار، دیدن تعداد عکس‌ها، بازشدن PDF و استخراج چند صفحه را روی تبلت آزمایش کنید.
- فایل‌های این مخزن، کد برنامه و کتابخانه‌های همراه آن هستند. اطلاعات شخصی، کدهای انتقال AZY، بانک اطلاعاتی دانش‌آموزان یا فایل کتاب‌های خصوصی را به مخزن اضافه نکنید.
- پس از اولین تست، قبل از انتشار عمومی، باید ساخت Release، امضای امن APK، مدیریت مجوزهای پوشه و بازیابی پوشه‌های انتخاب‌شده را جداگانه بازبینی کنیم.

## اجزای فنی

- Android Gradle Plugin 9.4.0 / Gradle 9.6.0 / JDK 17
- WebView با مبدأ HTTPS محلی `https://azmoon.local/` برای پشتیبانی از IndexedDB و ذخیره‌سازی وب
- Storage Access Framework برای انتخاب پوشه و مجوز پایدار
- GitHub Actions برای ساخت ابری APK

مراجع فنی: [Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files) و [Android Gradle Plugin compatibility](https://developer.android.com/build/releases/about-agp).
